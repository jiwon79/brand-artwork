# 웃음꽃 (Smile Flower) 아키텍처

웃음꽃은 꽃과 스마일 모델을 격자에 놓고, 손가락이나 마우스로 각 타일을 회전시키는 3D 작품이다. 드래그하면 타일이 뒤집히고, 길게 누르면 한 타일이 커진다. 손을 떼면 그 자리에서 회전 파동이 퍼진다.

## 용어

| 용어 | 뜻 | 코드 이름 |
| --- | --- | --- |
| 타일 | 격자의 한 자리와 그 자리에 놓인 꽃 또는 스마일 | `TILES` |
| 회전 상태 | 타일이 얼마나 돌았고 얼마나 빠르게 돌고 있는지 나타내는 값 | `TileRotationState` |
| 표시 배치 | 화면에 그릴 타일의 위치와 크기 | `tileLayouts` |
| 확대 중심 | 길게 누른 위치. 가까운 타일을 키우고 주변 타일을 밀어낸다. | `HoldFocus` |
| 회전 파동 | 손을 뗀 자리에서 바깥쪽 타일로 차례로 퍼지는 회전 | `RotationWave` |

## 장면이 만들어지는 순서

### 1. 타일을 만든다

`reference-layout.ts`에 저장된 격자 위치마다 꽃 타일을 하나씩 만든다. 꽃과 스마일 모델은 한 번만 불러오고, 각 타일은 같은 모델을 공유한다.

### 2. 포인터 움직임을 해석한다

포인터를 움직이면 드래그, 한곳에 머무르면 길게 누르기로 판단한다.

- 드래그할 때는 포인터가 지나간 타일을 찾는다.
- 길게 누를 때는 가장 가까운 타일을 확대 중심으로 삼는다.
- 여러 손가락을 사용하면 각 손가락의 상태를 따로 관리한다.

### 3. 타일의 회전과 배치를 계산한다

드래그가 지나간 타일에는 포인터의 이동 방향과 속도에 맞는 회전을 준다. 손을 뗀 뒤에도 회전은 잠시 이어지다가 가장 가까운 앞면이나 뒷면에서 멈춘다. 앞면에는 꽃, 뒷면에는 스마일을 표시한다.

길게 누르면 선택한 타일을 크게 만들고, 주변 타일은 겹치지 않도록 바깥으로 밀어낸다. 손을 떼면 타일은 원래 배치로 돌아가면서 가까운 곳부터 차례로 한 바퀴씩 돈다.

### 4. 한 프레임을 그린다

`script.ts`는 각 타일의 회전 상태와 표시 배치를 합쳐 위치, 크기, 회전이 담긴 행렬을 만든다. 같은 모델을 쓰는 타일은 `InstancedMesh`로 한꺼번에 그린다. 움직임이 있을 때만 행렬을 갱신하고 장면을 다시 그린다.

### 5. 색감과 재질감을 정한다

꽃잎, 중앙과 스마일에는 각각 다른 색을 적용한다. Roughness와 반사 강도로 무광 도자기에 가까운 표면을 만들고, 주 조명·보조 조명·테두리 조명으로 굴곡과 깊이를 드러낸다. 모델에 저장된 접촉 음영은 꽃잎 사이처럼 빛이 덜 닿는 곳을 보완한다. 마지막에는 노출과 tone mapping으로 화면 전체의 밝기와 대비를 정리한다.

색상, 재질과 조명이 함께 최종 인상을 만드는 원리는 [3D 모델의 색감과 재질감](../../concepts/3d-model-look-development.md)에 정리되어 있다.

## 출력

최종 결과는 검은 배경 위의 9:16 WebGL 장면이다. 꽃과 스마일은 서로 다른 모델이며, 타일이 옆면을 보일 때 모델을 바꿔 자연스럽게 뒤집히는 것처럼 보이게 한다.

## 검증

- `pnpm typecheck`: 타입과 모듈 연결 확인
- `pnpm test pages/smile-flower`: 작품별 회귀 테스트 확인
- `pnpm build`: 모델 경로와 번들 생성 확인
- 기존 Chrome 창: 드래그, 길게 누르기, 회전 파동 확인

모델을 다시 만들거나 내보내는 방법은 [웃음꽃 재현 가이드](./rebuild-guide.md)에 정리되어 있다.
