# Cursor Cat 아키텍처

Cursor Cat은 커서 위치에 맞춰 고양이가 그쪽을 바라보는 프레임을 고르는 작품이다. 고양이가 한 바퀴 돌아보는 모습을 120장의 이미지로 나누어 두고, 그중 가장 알맞은 한 장을 화면에 표시한다.

## 용어

| 용어 | 뜻 | 코드 이름 |
| --- | --- | --- |
| 눈 위치 | 각 프레임에서 두 눈 사이의 위치 | `eyePositionAnchors` |
| 커서 방향 | 눈 위치에서 현재 커서를 향하는 방향 | `pointerAngle` |
| 프레임 방향 | 해당 이미지 속 고양이가 바라보는 방향 | `frameLookAngle()` |
| 선택 프레임 | 현재 커서 방향과 가장 잘 맞는 이미지 | `selectFrameForPointer()` |
| 표시 위치 | 001번부터 120번까지 이어진 순환 경로에서 현재 화면이 가리키는 위치 | `displayFramePosition` |

R2 manifest는 기존 데이터와의 호환을 위해 눈 위치에 `gazeOrigins`라는 이름을 그대로 쓴다. 페이지 안에서는 같은 값을 `eyePositionAnchors`라고 부른다.

## 장면이 만들어지는 순서

### 1. 프레임을 준비한다

페이지 경로에 맞는 R2 manifest와 120장의 WebP 이미지를 미리 불러온다. 브라우저에서 바로 표시할 수 있도록 준비가 끝나면 고양이를 보여주고 포인터 입력을 받기 시작한다.

### 2. 커서에 맞는 프레임을 고른다

커서가 움직일 때마다 120장을 차례로 비교한다.

1. 후보 프레임의 눈 위치를 화면 좌표로 바꾼다.
2. 눈에서 커서로 향하는 방향을 구한다.
3. 이미지 속 고양이가 바라보는 방향과 얼마나 가까운지 비교한다.
4. 방향 차이가 가장 작은 프레임을 선택한다.

각 프레임의 눈 위치를 따로 쓰는 이유는 고양이가 고개를 돌릴 때 눈도 화면 안에서 함께 움직이기 때문이다.

### 3. 선택한 프레임까지 이동한다

120장의 프레임은 001번 다음에 002번이 이어지고, 120번 다음에는 다시 001번이 이어지는 원형 순서다. 현재 표시 위치에서 선택 프레임까지 더 가까운 쪽을 골라 이동한다. 예를 들어 120번에서 001번으로 갈 때는 한 바퀴를 거꾸로 돌지 않고 바로 다음 프레임으로 넘어간다.

화면에는 표시 위치와 가장 가까운 이미지 한 장만 보인다. 두 이미지를 섞거나 영상처럼 재생 위치를 옮기지 않는다.

### 4. 한 프레임을 그린다

선택한 WebP를 `<img>`에 넣고 manifest의 크기 보정값을 적용한다. 이미지 아래쪽을 기준으로 크기를 바꾸기 때문에 프레임마다 미세한 크기 차이가 있어도 고양이의 발밑은 흔들리지 않는다.

## 출력

최종 결과는 흰 배경 위에 놓인 투명 WebP 한 장이다. 모바일에서는 현재 화면 높이에 맞춰 이미지 아래쪽을 화면 아래에 붙인다.

`Angle / Frame / Final` 단계와 `?debug=1` 화면은 같은 계산 과정을 눈 위치, 선택 구간, 최종 이미지 순서로 나누어 보여준다.

## 검증

- manifest와 120장의 이미지가 모두 열리는지 확인한다.
- `pnpm typecheck`와 `pnpm test pages/cursor-cat`을 실행한다.
- `pnpm build`로 이미지 경로와 번들 생성을 확인한다.
- 기존 Chrome 창에서 오른쪽, 위, 왼쪽, 아래와 120번에서 001번으로 넘어가는 동작을 확인한다.
