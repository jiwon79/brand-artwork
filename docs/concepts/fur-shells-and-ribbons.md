# 털의 셸과 리본 렌더링

이 문서는 짧고 촘촘한 털을 그리는 두 방법을 설명한다. 셸은 겹친 표면으로 털의 두께를 채운다. 리본은 얇은 띠로 털 한 가닥을 그린다.

셸 렌더링과 리본 렌더링은 각각 사용할 수 있다. 이 문서의 제목은 두 기법을 함께 설명하기 위한 이름이다. 두 기법의 조합이 하나의 고정된 표준 알고리즘은 아니다.

왼쪽 곡선은 털 층의 단면이다. 각 곡선이 털 한 가닥을 뜻하지는 않는다. 점선 간격은 바깥층의 낮은 채움 계수를 나타낸다.

오른쪽 도형은 뿌리와 끝을 잇는 축에 폭을 더한 리본이다. 리본 중심선은 휨을 나타낸다. 리본 경계는 끝으로 갈수록 폭이 줄어드는 모습을 나타낸다.

## 2. 해결하려는 문제

몸체 색에 노이즈만 넣으면 표면이 거칠어 보인다. 그러나 외곽선 밖에는 털이 생기지 않는다.

모든 털을 가는 선으로 그리면 표면 사이의 빈 공간이 보인다. 카메라를 향하는 가닥은 화면에서 짧아진다. 그 가닥은 점처럼 보일 수 있다.

셸은 몸체 밖의 여러 높이에 털의 밀도를 배치한다. 이 층들이 솜 같은 두께를 만든다. 리본은 가닥의 길이, 휨, 끝을 표현한다. 두 방법을 함께 쓰면 촘촘한 내부와 외곽의 개별 가닥을 표현할 수 있다.

## 3. 용어, 입력, 출력

본문은 같은 대상에 같은 용어를 사용한다.

| 용어 | 의미 | 영어 대응 |
| --- | --- | --- |
| 셸 | 몸체 밖에 겹쳐 그리는 반투명 표면이다. | `shell` |
| 리본 | 털 한 가닥을 그리는 얇은 삼각형 띠다. | `ribbon` |
| 표면 법선 | 표면에 수직인 방향이다. | `normal` |
| 성장 방향 | 털이 몸체에서 뻗는 방향이다. | `growth direction` |
| 카메라 공간 | 카메라를 기준으로 표현한 3D 좌표 공간이다. | `view space` |
| 채움 계수 | 털 층을 얼마나 채울지 정하는 0~1 값이다. | `coverage` |
| 불투명도 | 색을 합성할 때 사용하는 값이다. 0은 완전 투명, 1은 완전 불투명이다. | `alpha` |
| 분할점 | 리본의 길이 방향을 나누는 위치다. | `station` |
| 정점 | 기하 데이터에 저장한 점이다. | `vertex` |
| 프래그먼트 | 삼각형을 화면에 그릴 때 생성하는 색·깊이 계산 단위다. | `fragment` |
| 인스턴싱 | 여러 가닥이 같은 기하 데이터를 공유하는 그리기 방식이다. | `instancing` |
| 표면 바인딩 | 기준 위치와 변형 가중치를 저장한 데이터다. | `binding` |

수식의 입력은 다음과 같다.

| 기호 | 의미와 좌표 공간 |
| --- | --- |
| `B` | 현재 몸체의 3D 표면점이다. 캐릭터 로컬 공간의 위치다. |
| `D` | 셸의 확장 방향이다. 로컬 공간의 단위 벡터다. 법선 또는 지정한 성장 방향을 사용한다. |
| `ℓ_j` | 셸 `j`의 정규화 높이다. 안쪽은 0, 바깥쪽은 1이다. |
| `h(ℓ)` | 몸체에서 셸까지의 거리다. 몸체와 같은 길이 단위를 사용한다. |
| `S_j` | 확장한 셸의 위치다. |
| `R`, `T` | 변형 후 털의 뿌리와 끝이다. 로컬 공간의 위치다. |
| `M` | 로컬 위치를 카메라 공간으로 옮기는 모델뷰 행렬이다. |
| `R_v`, `T_v` | 카메라 공간의 뿌리와 끝이다. |
| `U` | 카메라 공간의 XY에 투영한 뿌리–끝 축이다. 2D 방향 벡터다. |
| `A` | `U`에 수직인 화면 폭 방향이다. 길이는 1이다. |
| `t` | 리본의 길이 좌표다. 뿌리는 0, 끝은 1이다. |
| `a` | 리본의 폭 좌표다. 왼쪽은 -1, 오른쪽은 1이다. |
| `w(t)` | 리본의 반폭이다. 카메라 공간의 길이 단위를 사용한다. |
| `b` | 리본 중간의 최대 휨 거리다. 카메라 공간의 길이 단위를 사용한다. |
| `c` | 밀도 표본에서 얻은 채움 계수다. 범위는 0~1이다. |
| `α`, `C` | 프래그먼트의 불투명도와 색이다. |

기하 계산의 출력은 셸과 리본의 삼각형이다. 셰이더의 출력은 각 프래그먼트의 RGBA다.

`R_v.xy`는 위치다. `A`는 방향이다. `(t,a)`는 리본 내부 좌표다. 이 값들은 서로 바꿔 사용할 수 없다.

## 4. 셸로 두께 채우기

셸은 몸체 표면을 복제한다. 각 정점을 몸체 밖으로 옮기면 한 층이 생긴다. 셸 `j`의 위치는 다음과 같다.

\[
S_j = B + h(\ell_j)D
\]

거리 `h`가 커지면 셸은 몸체에서 멀어진다. `D`에 법선을 사용하면 현재 표면에 수직으로 확장한다. `D`에 성장 방향을 사용하면 털의 기울기를 따른다.

고정된 기준 방향을 사용하면 방향 계산이 간단해진다. 그러나 변형 후의 셸 두께가 일정하다는 보장은 없다.

높이별 간격은 다음 함수로 조절할 수 있다. `h_0`는 가장 안쪽 셸의 거리다. `H`는 추가 두께다. `p>0`은 간격 분포를 정하는 지수다.

\[
h(\ell)=h_0+H\ell^p
\]

| 지수 | 셸 간격 |
| --- | --- |
| `p=1` | 간격이 같다. |
| `p>1` | 안쪽 간격이 좁다. 바깥쪽 간격이 넓다. |
| `0<p<1` | 안쪽 간격이 넓다. 바깥쪽 간격이 좁다. |

높이의 작은 변화에 대한 거리 변화율은 `h'(ℓ)=Hpℓ^(p-1)`이다. 이 값이 작으면 이웃 셸의 간격이 좁다. 이 값이 크면 이웃 셸의 간격이 넓다.

모든 셸을 불투명하게 그리면 가장 바깥의 매끈한 표면만 보인다. 셸 사이를 보이게 하려면 채움 계수와 높이 감쇠로 불투명도를 계산한다. `a_0`는 층의 기본 불투명도다. `q>0`은 높이 감쇠 지수다.

\[
\alpha_{shell}=a_0\,c\,(1-\ell)^q
\]

`c=0`인 위치는 비어 있다. `c=1`인 위치는 해당 층의 기본 불투명도를 사용한다. `ℓ=1`이면 불투명도는 0이다. `q`가 커질수록 바깥층의 불투명도가 빨리 줄어든다.

밀도는 표면 UV와 높이로 3D 텍스처를 조회해 구할 수 있다. 절차적으로 계산한 3D 노이즈도 사용할 수 있다. 한 가닥이 여러 층을 통과하는 모습이 필요하면 층 사이의 밀도 표본을 연속으로 만든다.

정점 계산은 셸 위치를 구한다. 프래그먼트 계산은 채움 계수와 불투명도를 구한다. 기하 데이터와 높이는 미리 저장할 수 있다. 표면이 움직이면 CPU가 위치 버퍼를 갱신하거나 정점 셰이더가 표면을 확장한다.

## 5. 리본을 카메라 쪽으로 펼치기

3D 선분에는 길이만 있다. 화면에서 폭을 유지하려면 선분 양쪽에 정점을 추가해야 한다. 먼저 뿌리와 끝을 카메라 공간으로 옮긴다.

아래 식은 정사영 카메라 또는 카메라 공간에서 만든 리본에 적용한다.

\[
R_v=M(R,1),\quad T_v=M(T,1),\quad U=T_v.xy-R_v.xy
\]

`U=(u_x,u_y)`는 화면에 투영한 축이다. `(-u_y,u_x)`는 이 축에 수직이다. 두 벡터의 내적은 `-u_xu_y+u_yu_x=0`이기 때문이다.

수직 벡터의 길이를 1로 맞추면 가닥 길이가 리본 폭을 바꾸지 않는다. 화면 폭 방향 `A`는 다음과 같다.

\[
A=\frac{(-u_y,u_x)}{\lVert U\rVert}
\]

`ε`은 작은 양수 임계값이다. `‖U‖`가 `ε`보다 작으면 이 나눗셈을 수행하지 않는다. 이 경우 `A=(1,0)` 같은 고정 방향을 사용한다.

카메라를 향하는 가닥은 뿌리와 끝의 화면 위치가 거의 같다. 고정 방향은 이 경우의 수치 오류를 막는다. 그러나 가닥의 투영 길이를 늘리지는 않는다.

리본의 폭은 끝으로 갈수록 줄인다. `w_0`는 뿌리의 반폭이다. `r>0`은 폭 감쇠 지수다.

\[
w(t)=w_0(1-t)^r
\]

리본 위치 `P_v`는 중심 위치, 휨, 폭을 합해 구한다. 2D 방향 `A`의 Z 성분은 0으로 둔다.

\[
P_v(t,a)=(1-t)R_v+tT_v+(A_x,A_y,0)\left[b\sin(\pi t)+a\,w(t)\right]
\]

각 항의 역할은 다음과 같다.

| 항 | 역할 |
| --- | --- |
| `(1-t)R_v+tT_v` | 뿌리와 끝 사이의 직선 위치를 구한다. |
| `b sin(πt)` | 리본 중간을 화면 폭 방향으로 휜다. |
| `a w(t)` | 중심선 양쪽에 폭을 더한다. |

`sin(πt)`는 `t=0`과 `t=1`에서 0이다. 따라서 휨은 두 끝점을 움직이지 않는다. `t=1/2`에서는 휨이 최대다.

반폭은 뿌리에서 `w_0`이고 끝에서 0이다. 이 변화가 뾰족한 끝을 만든다. 지수 `r`가 커지면 리본은 더 빨리 가늘어진다.

삼각형은 다음 순서로 만든다.

1. 길이 방향에 여러 분할점 `t`를 둔다.
2. 각 분할점에 폭 좌표 `a=-1,+1`인 정점을 둔다.
3. 이웃 분할점을 두 삼각형으로 연결한다.

분할점이 적으면 계산 비용이 낮다. 그러나 리본의 휨이 꺾여 보일 수 있다.

인스턴싱은 하나의 리본 기하 데이터를 여러 가닥이 공유하게 한다. 가닥별 뿌리, 끝, 폭, 휨은 인스턴스 속성으로 전달한다. 각 가닥에 별도 메시를 만들 필요가 없다.

원근 카메라에서도 카메라 공간의 리본을 사용할 수 있다. 이 경우 깊이에 따라 화면 폭이 작아진다. 일정한 픽셀 폭이 필요하면 화면 공간에서 축과 폭을 계산한다.

화면 공간 위치는 클립 좌표를 그 좌표의 `w` 성분으로 나누어 구한다. 폭 계산 후에는 위치를 클립 공간으로 되돌린다.

## 6. 리본의 가장자리와 겹침

삼각형 띠의 경계가 그대로 보이면 리본이 평평한 종이처럼 보인다. 폭 가장자리와 끝에서 불투명도를 줄이면 이 경계를 줄일 수 있다.

`a_s∈[0,1)`는 폭 감쇠 시작점이다. `s>0`은 끝 감쇠 지수다. `α_0`는 기본 불투명도다. `e(a)`는 폭 감쇠 계수이며, `f(t)`는 끝 감쇠 계수다.

\[
e(a)=1-\operatorname{smoothstep}(a_s,1,|a|),\quad
f(t)=(1-t)^s
\]

\[
\alpha_{ribbon}=\alpha_0\,e(a)\,f(t)
\]

리본 중앙 `a=0`은 잘 보인다. 양쪽 경계 `|a|=1`은 투명해진다. 길이 좌표 `t`가 끝에 가까워질수록 불투명도는 줄어든다.

`smoothstep`은 감쇠의 시작과 끝에서 기울기를 0으로 만든다. 이 처리는 갑자기 잘린 경계를 줄인다. 기하 계산의 폭 감쇠는 리본을 가늘게 만든다. 불투명도 감쇠는 리본을 옅게 만든다.

외곽 가닥을 강조하는 보조값은 표면 법선 또는 성장 방향에서 구할 수 있다. `N_v`는 카메라 공간의 단위 법선이다. `D_v`는 카메라 공간의 단위 성장 방향이다. `μ_N`과 `μ_D`는 각각의 보조값이다.

\[
\mu_N=1-|N_v.z|,\qquad \mu_D=1-|D_v.z|
\]

표면 또는 가닥이 카메라 옆을 향하면 값은 1에 가깝다. 카메라 축과 나란하면 값은 0에 가깝다. 표면 법선과 성장 방향은 서로 다른 대상이다. 이 값으로 불투명도를 높이는 방법은 시각적 근사다. 실제 털의 빛 산란을 계산하는 방법은 아니다.

일반 불투명도 합성은 현재 색과 뒤쪽 색을 섞는다. `C_s`는 현재 색, `C_d`는 뒤쪽 색, `α_s`는 현재 불투명도다. 합성 색은 `C_out=α_s C_s+(1-α_s)C_d`다.

그리기 순서를 바꾸면 합성 결과도 달라진다. 따라서 투명 도형은 보통 뒤에서 앞으로 그린다. `depthWrite=false`는 투명 조각의 깊이 기록을 끈다. 이 설정은 앞쪽 투명 조각이 뒤쪽 조각을 완전히 가리는 문제를 줄인다. 그러나 깊이 정렬을 대신하지는 않는다.

## 7. 변형과 일반 의사 코드

뿌리와 끝이 서로 다른 변형을 받으면 가닥이 표면에서 미끄러질 수 있다. 가닥이 과하게 늘어날 수도 있다. 한 방법은 기준 뿌리의 가중치를 기준 끝에도 사용하는 것이다.

같은 가중치를 사용해도 가닥의 길이 보존과 충돌을 보장하지는 않는다. 이 방법은 별도의 물리 시뮬레이션을 대체하지 않는다.

```text
초기화 또는 형태 교체:
  기준 표면의 위치와 변형 가중치를 저장한다.
  각 가닥의 기준 뿌리를 저장한다.
  각 가닥의 기준 끝을 저장한다.
  각 가닥의 뿌리 가중치를 저장한다.
  공유 리본 기하 데이터를 만든다.
  가닥별 인스턴스 속성을 만든다.

매 프레임:
  몸체점 = 변형(표면 바인딩)
  뿌리 = 변형(기준 뿌리, 뿌리 가중치)
  끝 = 변형(기준 끝, 뿌리 가중치)

셸 정점:
  셸 위치 = 몸체점 + 높이(층) * 성장 방향

리본 정점:
  뿌리와 끝을 카메라 공간으로 옮긴다.
  투영 축에서 화면 폭 방향을 구한다.
  축이 너무 짧으면 고정 폭 방향을 사용한다.
  중심 위치, 휨, 폭을 합해 정점 위치를 구한다.

프래그먼트:
  셸은 밀도 표본과 높이 감쇠로 불투명도를 구한다.
  리본은 폭 가장자리와 끝 감쇠로 불투명도를 구한다.
  선택한 합성 방식으로 색을 누적한다.
```

계산 빈도와 저장 위치는 다음과 같다.

| 데이터 또는 계산 | 빈도와 위치 |
| --- | --- |
| 기준 표면 바인딩·가닥 속성 | 초기화 또는 형태 교체 때 계산한다. 저장한 값을 재사용한다. |
| 변형된 뿌리·끝 | 매 프레임 갱신한다. |
| 화면 폭 방향·폭 감쇠 | 리본 정점마다 계산한다. |
| 채움 계수·가장자리 불투명도 | 프래그먼트마다 계산한다. |

## 8. 일반적인 사용, 한계, 대안

이 방식은 짧은 털, 솜, 플러시 표면에 사용할 수 있다. 촘촘한 두께와 외곽 가닥을 함께 표현할 때 유용하다.

셸 비용은 겹치는 프래그먼트 수에 따라 증가한다. 리본 비용은 가닥 수와 분할점 수에 따라 증가한다. 인스턴싱은 그리기 호출과 기하 데이터 중복을 줄인다. 그러나 투명 영역을 여러 번 칠하는 비용은 남는다.

| 상황 | 한계 | 대안 |
| --- | --- | --- |
| 강한 변형 | 고정 성장 방향이 표면 법선과 어긋날 수 있다. | 변형에 맞춰 법선·접선·성장 방향을 갱신한다. |
| 카메라를 향하는 가닥 | 투영 길이가 짧아진다. | 작은 평면, 여러 방향 평면, 원통 기하를 사용한다. |
| 가까운 확대 | 셸 층이나 리본의 평면이 드러날 수 있다. | 분할점을 늘린다. 실제 가닥 기하 또는 거리별 상세 수준(LOD)을 사용한다. |
| 투명 도형의 겹침 | 가닥별 깊이 정렬의 비용이 크다. | 알파 검사, 알파 투 커버리지, 순서 독립 투명도 합성을 검토한다. |
| 긴 머리카락 | 이 방식만으로 관성·충돌·꼬임을 계산하지 않는다. | 가닥 동역학과 방향성 빛 산란 모델을 추가한다. |

알파 검사(alpha test)는 불투명도 기준으로 프래그먼트를 남기거나 버린다. 알파 투 커버리지(alpha-to-coverage)는 불투명도를 멀티샘플 마스크로 바꾼다. 순서 독립 투명도 합성(order-independent transparency)은 정렬 의존성을 줄이는 별도 합성 기법이다. 이 대안들은 품질과 비용이 서로 다르다.

셸과 핀을 함께 쓰는 대표적인 원전은 [Lengyel 등의 *Real-Time Fur over Arbitrary Surfaces* (2001)](https://gfx.cs.princeton.edu/pubs/Lengyel_2001_RFO/index.php)이다. 핀(fin)은 표면에 수직으로 놓은 도형이다. 이 논문은 핀에 털의 3D 밀도 텍스처 단면을 붙인다.

이 문서의 리본은 가닥별로 폭을 만든다. 리본 폭은 카메라의 투영 축에서 구한다. 따라서 핀과 카메라 방향 리본(billboard ribbon)을 구분해 부른다.
