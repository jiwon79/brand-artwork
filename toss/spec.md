# Toss Wireframe — 구조 정리

## 1. 토스 로고 구성

토스 로고는 **동일한 곡선 하나를 180도 회전**시켜 두 개의 패스로 구성된다.

### 원본 패스 (toss-half.svg)

```
M 177.784 313.236
C 103.789 323.675  41.638 299.053   21.147 270.736   ← 왼쪽 외곽 하단
C -54.353 166.402  107.797 18.790  256.784   2.236   ← 왼쪽 외곽 상단
C 256.56   38.471  254.264  57.873  248.784  91.236   ← 블레이드 상단 (AB)
```

### 회전 패스 (원본을 중심점 기준 180도 회전 후 offset 적용)

```
M 248.784  91.236
C 322.779  80.797  384.930 105.419  405.421 133.736   ← 오른쪽 외곽 상단
C 480.921 238.070  318.771 385.682  169.784 402.236   ← 오른쪽 외곽 하단
C 170.008 366.001  172.304 346.599  177.784 313.236   ← 블레이드 하단 (CD)
```

### 오프셋 계산

- 회전 후 시작점: `(81.216, 4.764)`
- 원본 끝점: `(248.784, 91.236)`
- 적용 offset: `(+167.568, +86.472)` → 두 패스의 끝점이 수학적으로 정확히 일치

## 2. 핵심 4개 점 (A, B, C, D)

```
        A (256.784, 2.236)
        │  ← 블레이드 AB
        B (248.784, 91.236)
       ╱ ╲
  왼쪽    오른쪽
  외곽    외곽
       ╲ ╱
        C (177.784, 313.236)
        │  ← 블레이드 CD
```

## 3. 그려지는 선들

### 외곽선

- **왼쪽 외곽**: `outerL(t)` — C(t=0) → A(t=1), 원본 패스 첫 두 세그먼트
- **오른쪽 외곽**: `outerR(t)` — B(t=0) → D(t=1), 회전 패스 첫 두 세그먼트

### 블레이드 선

- **AB**: `A → B` 곡선 — 원본 SVG 마지막 세그먼트 제어점 그대로 사용
- **CD**: `C → D` 곡선 — 회전 패스 마지막 세그먼트 제어점
- **AD**: `A → D` 직선 — 블레이드 전체를 관통하는 세로선

### 보간 채우기 선

두 섹션 각각에 40개의 곡선을 생성.

```
alpha = i / N   (i: 0 → N)

tStart = alpha × 0.5        // 시작점이 외곽 위를 슬라이드 (0 → 0.5)
tEnd   = 1.0 - alpha × 0.5  // 끝점이 외곽 위를 슬라이드 (1 → 0.5)

P1  = outerFn(tStart)   // 시작점
P2  = outerFn(tEnd)     // 끝점
Mid = outerFn(0.5)      // 외곽 극단점 (곡률 제어용)

CP = midLine + alpha × (Mid - midLine)  // 중간점 → 극단 방향으로 휘어짐

quadraticCurveTo(CP, P2)
```

- `alpha=0`: P1=C, P2=A → AC 직선에 가까움
- `alpha=1`: P1=P2=극단점 → 외곽선 자체에 수렴
