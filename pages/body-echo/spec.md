# Body Echo

첨부 영상 속 작은 TFT 작품을 웹용 인터랙티브 아트워크로 재구현한다.

## 시각 구성

- 검은 화면 위에 인체 형상 여섯 개가 오른쪽으로 겹쳐진다.
- 오른쪽 잔상일수록 크기가 작고 조밀하다.
- 빨강, 초록, 파랑 채널은 서로 조금씩 어긋나며, 겹치는 곳은 흰색으로 밝아진다.
- 기본 인체는 점이 아니라 둥근 연속 스트로크로 이루어진 `Lines` 모드다.
- 사용자가 제공한 여섯 SVG를 왼쪽부터 순서대로 사용해, 성긴 연속선에서 조밀한 실루엣으로 밀도를 높인다.
- 마지막 SVG의 상체는 촘촘한 선과 RGB 가산 합성이 겹쳐 면처럼 보이며, 하체는 촘촘한 개별 선을 유지한다.
- 같은 마스크를 조밀하게 샘플링한 `Solid` 모드를 함께 제공한다.
- 미세한 화면 모아레나 카메라 압축 노이즈는 재현 대상에서 제외하고, 고해상도 캔버스의 작은 글로우와 스캔라인으로 TFT 질감만 유지한다.

## 입력과 상태

1. `idle`: 인체 잔상이 작은 파동을 유지한다.
2. `Original`은 클릭, 터치, `Space`, `Enter`를 누르면 바로 시작한다. `NameDrop Wave`는 입력을 누르고 있는 동안 `gathering` 상태를 유지하고, 손가락·포인터·키를 떼는 순간 `dissolving`으로 전환한다. `Drag Dissolve`는 손가락이나 포인터를 누른 채 이동하는 동안 `dragging` 상태를 유지한다.
3. `Original`: 붕괴 전선이 왼쪽에서 오른쪽으로 이동하고, 분리된 RGB 입자는 오른쪽으로 확산한다.
4. `NameDrop Wave`: 누르고 있는 동안 별도 점이나 꼬리를 생성하지 않고 실제 SVG 경로 자체를 현재 입력 좌표 쪽으로 국소적으로 늘인다. 손가락이나 포인터가 움직일 때마다 접촉 좌표를 갱신해 당겨진 경로가 계속 따라간다. 작품 영역 밖의 검은 여백에서도 좌표를 가장자리로 강제 제한하지 않으며, 손을 떼는 순간의 최종 포인터 좌표까지 반영해 파동 중심과 실제 손 위치를 일치시킨다. 멀리 있는 구간은 고정되고 가까운 구간일수록 크게 당겨져, 여러 줄을 한 손으로 잡아당기는 장력을 만든다. 빨강·초록·파랑 경로의 간격은 줄이지 않아 크로마틱 효과를 유지한다. 입력을 떼면 터치점에서 별도 파티클을 만들지 않고, 바깥으로 진행하는 파동이 도달한 SVG 경로 구간만 그 자리에서 파티클로 분해한다. 화면 안쪽을 채우는 밝은 원이나 얇고 단단한 테두리는 그리지 않고, Toss 당겨서 새로고침 레퍼런스처럼 진행 전선 주변의 넓고 부드러운 주 파동과 약한 후행 파동만 표시한다.
5. `Drag Dissolve`: 한 손가락 드래그는 이전 좌표와 현재 좌표 사이를 하나의 연속 브러시 선분으로 판정한다. 두 손가락이 닿으면 두 접점 사이에 가는 RGB 연결선을 표시하고, 연결선의 좁은 충돌 반경 안에 들어온 실제 SVG 경로 샘플만 제거한다. 어느 손가락이 움직여도 이전 연결선과 새 연결선 사이를 보간해 빠른 두 손가락 드래그에도 분해 영역이 끊기지 않게 한다. 제거된 각 샘플의 정확한 위치에서 RGB 파티클을 만들며, 파티클은 드래그 또는 연결선 방향을 따라가면서 작은 수직 확산과 난류를 더한다. 한 손가락만 남으면 즉시 단일 브러시로 돌아가고, 두 손가락을 모두 뗀 뒤 파티클 수명과 복귀 지연이 지나면 전체 SVG를 원상 복구한다. 이 모드는 SVG 경로를 사용하는 `Lines` 전용이다.
6. `NameDrop Wave`의 입자가 모두 날아간 뒤에는 자동으로 `idle`의 원래 인체 형상으로 복귀한다. `Original`만 `blank`에 머물며 다음 입력을 기다린다.

키보드 `M`은 두 인체 모드를 전환하고 `R`은 초기 상태로 돌아간다. `G` 또는 `?debug=1`로 lil-gui를 열어 `Interaction`의 `Original / NameDrop Wave / Drag Dissolve`, 잔상 수, RGB 간격, 붕괴 속도, 모이는 시간, 장력 상승 시간, 선 당김, 파동 확산 시간, SVG 파티클 밀도와 크기, 해방 속도와 화면 질감을 조절한다. `Drag Dissolve` 폴더에서는 한 손가락 브러시 반경, 두 손가락 연결선의 충돌 반경과 굵기, 파티클 크기·힘·확산·수명과 원상 복귀 지연을 조절한다.

화면 아래의 렌더 단계 컨트롤은 실제 작품 캔버스에 효과를 누적 적용한다. `LINE`은 단색 SVG 경로만, `CHROMATIC`은 RGB 채널 분리까지, `PULL`은 화면 중앙 아래 지점으로 SVG 경로를 당긴 상태까지 보여준다. `WAVE`는 같은 지점에서 퍼지는 파동과 당겨진 선을 유지하며, 파동 전선이 실제 SVG 샘플과 교차하는 지점을 RGB 발광 픽셀로 표시해 경로 판정 과정을 드러낸다. `DISSOLVE`는 파동이 지난 샘플을 입자로 분해하는 최종 결과를 표시한다. 마지막 `INTERACT`는 자동 재생 없이 원본 작품으로 돌아가 사용자가 캔버스를 직접 누르고 당긴 뒤 놓아 전체 인터랙션을 실행할 수 있다. 단계 버튼을 선택하면 현재 상태를 초기화하며, `PULL`, `WAVE`, `DISSOLVE`는 중앙 아래 접촉을 자동 재생해 차이를 바로 확인할 수 있다. 숫자 `1`~`6`과 좌우 화살표 키로도 단계를 바꿀 수 있다.

## 기본 타이밍

- 입력 후 유지: 약 `0.72초`
- 왼쪽 → 오른쪽 붕괴: 약 `3.25초`
- 입자 잔류: 최대 약 `3.35초`
- 전체 시퀀스: 약 `7.8초`

`NameDrop Wave`는 기본 `Pull Amount 100`, `Pull Speed 1.8`을 사용한다. 기준 시간 `0.92초` 동안의 당김과 이어지는 `0.52초` 동안의 장력 상승을 속도 배율로 나눠 재생하므로, 기본 상태에서는 각각 약 `0.51초`, `0.29초`가 걸린다. RGB 경로 간격은 전 구간에서 그대로 유지한다. 그보다 오래 눌러도 해방은 자동 실행되지 않고 최대 장력에서 미세하게 맥동하며 움직이는 접촉점을 추적한다. 입력을 떼면 중심과의 거리에 따른 기본 `1.24초`의 파동 지연에 최대 `0.08초`의 작은 방출 시차만 섞어 해방한다. 화면에 보이는 넓고 부드러운 파동 전선과 SVG 샘플의 분해 반경은 동일한 선형 시간축을 사용하므로, 전선이 지나간 위치에서 차례대로 픽셀이 생성된다. 파티클은 별도의 임의 분포가 아니라 SVG 경로를 따라 샘플링하며, 기본 밀도에서는 기존보다 세 배 많은 전체 경로 샘플을 사용한다. 크기는 기존 해방 파티클의 약 `55%`를 기본값으로 사용한다. 해방 후 개별 파티클의 이동과 감쇠는 기본 시간축의 `1.5배` 속도로 재생한다. 파티클 수명이 끝나면 즉시 초기 SVG 렌더링으로 복귀한다.

`Lines` 모드는 각 SVG의 실제 Bézier 경로를 `Path2D`로 직접 그린다. 붕괴할 때는 같은 경로의 각 `M` 서브패스를 독립적으로 샘플링해, 분리된 팔·몸통·다리 사이가 임의의 직선으로 연결되지 않도록 한다. `NameDrop Wave`는 이 샘플을 연속선으로 다시 연결한 상태에서 접촉점과의 거리에 따라 경로를 탄성 변형하고, 손을 뗀 뒤에는 파동이 도달한 SVG 샘플 자체만 파티클의 출발점으로 사용한다. 터치 중심에서는 독립 파티클을 생성하지 않는다. `Solid` 모드는 기존 사진에서 복원한 마스크를 유지한다. 픽셀 사각형은 시작 장면이나 홀드 단계에서 사용하지 않고 해방 파동이 도달한 경로 구간에서만 생성한다.
