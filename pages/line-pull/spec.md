# Line Pull — 인터랙티브 라인 리빌 스펙

## 컨셉

검은 화면을 채운 수평선 사이 어디서든 드래그를 시작한다. 포인터가 이동 방향에서 처음 교차한 선이 활성선이 되고, 활성선과 현재 포인터 사이에 들어온 모든 선의 중앙 앵커가 포인터 한 점으로 모인다. 활성선의 원본 수평선은 그대로 남고, 별도의 당겨진 복사본과 원본 사이에서 숨은 타이포그래피 패널이 드러난다.

영상에서 보인 네 선은 고정된 묶음이 아니다. 약 네 줄 높이만큼 당긴 결과다. 당김 거리가 커지면 영향받는 선의 수도 제한 없이 늘어난다.

## 입력

- 마우스, 펜, 터치의 `pointerdown`으로 시작한다.
- 누른 지점이 선 위라면 그 선을 즉시 활성화한다.
- 누른 지점이 선 사이라면 아직 어떤 선도 활성화하지 않는다. 포인터의 이동 구간이 처음 교차한 선을 드래그 방향과 무관하게 활성화한다.
- X 좌표는 연속값이며 화면의 어느 가로 위치에서도 꼭짓점을 만들 수 있다.
- `setPointerCapture`를 사용해 포인터가 화면 밖으로 나가도 드래그를 유지한다.
- 한 번에 첫 번째 포인터 하나만 사용한다.
- 복원 애니메이션 중 새 `pointerdown`이 오면 이전 복원을 즉시 끊고 새 드래그를 시작한다. 시각적으로 복원이 끝난 뒤 남아 있는 물리 임계값 때문에 입력이 잠기는 구간을 만들지 않는다.

## 선 선택

처음 교차한 활성선 높이를 `originY`, 현재 꼭짓점 높이를 `apexY`, 각 선의 원래 높이를 `lineY`라고 한다. 교차 전에는 대기 상태이며 변형과 리빌을 렌더링하지 않는다.

```ts
minY = min(originY, apexY)
maxY = max(originY, apexY)
pulled = lineY >= minY && lineY <= maxY
```

당기는 방향과 무관하게 시작점과 꼭짓점 사이에 들어온 모든 선을 선택한다. 포인터가 새 선을 지나는 순간 그 선의 변형량은 거의 0이므로, 활성 선 개수가 바뀌어도 시각적 점프가 생기지 않는다.

## 선 지오메트리

당겨진 선은 세 점을 잇는 SVG path다.

```ts
M 0,lineY
L apexX,apexY
L viewportWidth,lineY
```

최초 활성선은 같은 선을 두 path로 분리한다. 포인터를 따라가는 당김 path는 드래그 방향으로 이동하고, 리빌의 반대쪽 경계 path는 당김 거리에 비례해 반대 방향으로 계속 이동한다. 반대쪽 경계에도 렌즈 왜곡을 더하므로 주변 격자와 따로 노는 평행 이동처럼 보이지 않는다. 두 선이 동시에 벌어지기 때문에 한 선을 복제해 한쪽만 당긴 인상 대신, 원래 선이 위·아래로 갈라져 공간을 여는 인상이 난다. 이후 교차한 선은 기존처럼 당김 path로 바뀐다. 모든 활성 선이 하나의 꼭짓점을 공유하므로 긴 드래그에서도 정확히 한 점으로 수렴한다.

## 패널 클리핑

패널은 드래그 반대 방향으로 밀리는 활성선 경계와 포인터를 따라가는 당김 경계 사이의 도형으로 정의한다. 드래그 높이에 고정 상한이나 행 개수 제한을 두지 않으며 위·아래 방향에 같은 도형을 사용한다.

패널 내부로 들어온 이후 격자선은 당김 path로 바뀌어 한 꼭짓점으로 모이고, 반대쪽으로 이동한 활성선 복사본이 수평 경계로 남는다. 클리핑 도형은 이 경계와 당김 path의 양쪽 끝 및 꼭짓점을 모두 따라가므로 두 선 사이가 화면 가장자리까지 끊김 없이 열린다. 패널과 문자는 변형하지 않고 `clipPath`만 갱신하므로 문자가 선과 함께 늘어나거나 찌그러지지 않는다.

## 표면 왜곡과 질감

기본 선은 평면 직선이 아니라 화면 중앙을 기준으로 매우 약한 핀쿠션 곡률을 적용한다. 당기는 동안에는 반대쪽 격자를 이동한 활성선 경계에, 포인터 바깥쪽 격자를 꼭짓점에 각각 고정하고 두 영역의 선 간격을 확대한다. 확대율은 당김 거리에 따라 감쇠 없이 증가하고 가로 방향으로만 부드럽게 약해져, 포인터가 원점에서 멀어져도 처음 확대된 영역이 다시 줄어들지 않는다. `originY`와 `apexY`의 중간을 transform origin으로 최대 `3.5%` 추가 확대하며 복원과 함께 사라진다.

레퍼런스의 직물·LED 망점은 CSS로 생성한 노이즈가 아니라 제공 영상의 빈 검정 영역에서 추출한 `assets/reference-screen-texture.webp`를 사용한다. 무채색으로 정규화한 실제 표면 패턴을 `screen`과 `multiply` 두 레이어로 겹쳐 검정 배경, 선, 패널, 문자에 같은 물성을 부여한다.

## 복원

포인터를 놓으면 꼭짓점 Y 하나만 감쇠 스프링으로 `originY`까지 돌려보낸다.

```ts
velocity += (originY - apexY) * stiffness * dt
velocity *= exp(-damping * dt)
apexY += velocity * dt
```

꼭짓점이 원점으로 돌아오는 동안 영향 구간이 짧아지므로 선들이 바깥쪽부터 하나씩 자연스럽게 풀린다. `prefers-reduced-motion`에서는 즉시 닫는다.

## 반응형 및 예외 처리

- 줄 간격은 CSS 픽셀이며 뷰포트 높이에 맞춰 필요한 선 수를 다시 만든다.
- 화면 리사이즈 중인 드래그는 즉시 종료해 좌표 불일치를 막는다.
- `pointercancel`, `lostpointercapture`, 창 포커스 해제 시 복원한다.
- 세로 꼭짓점은 화면 밖 좌표도 허용하며 SVG 뷰포트가 자연스럽게 잘라낸다.
- 디버그 파라미터는 `?debug`에서 lil-gui로 조절한다.
