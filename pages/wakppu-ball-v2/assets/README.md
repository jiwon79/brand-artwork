# Wakppu crack audio samples

Put local or licensed wax-crack audio files in this directory when you want the built-in presets to play sound.

Expected preset filenames:

- `wakppu-crack-crunchy.mp3`, `wakppu-crack-crunchy.m4a`, or `wakppu-crack-crunchy.wav`
- `wakppu-crack-relaxation.mp3`, `wakppu-crack-relaxation.m4a`, or `wakppu-crack-relaxation.wav`
- `wakppu-crack-compilation.mp3`, `wakppu-crack-compilation.m4a`, or `wakppu-crack-compilation.wav`

You can also use the `로컬 소리 선택` control in the page to load audio files without adding them to the repo.
