# 애플이 40년간 바꾸지 않은 단 하나의 것

## 원문 캡션

> 애플은 아이콘 모서리에 40년 동안 단 한 번도 평범한 원호를 쓰지 않았습니다.
>
> 일반 아이콘의 모서리는 원의 일부를 잘라 붙인 것입니다. 곡선이 직선과 만나는 순간, 눈에 보이지 않는 꺾임이 생기고 우리 뇌는 그 부자연스러움을 무의식적으로 감지합니다. 애플이 선택한 슈퍼엘립스는 |x|ⁿ + |y|ⁿ = rⁿ 공식으로 표현되는 곡선으로, n=2.5일 때 모서리와 직선이 단절 없이 하나로 이어집니다. "애플 제품은 왠지 더 예뻐 보인다"는 느낌의 정체 중 하나가 바로 이것입니다.
>
> 이 곡선을 활용해 인터랙티브 아트를 만들었습니다. 화면을 가득 채운 슈퍼엘립스 격자 위에 손가락으로 글씨를 쓰면, 닿은 자리의 모서리들이 둥글어지며 글자가 떠오릅니다. 브러시와의 거리에 따라 각 모서리의 곡률이 달라지고, 시간이 지나면 서서히 원래의 격자로 돌아갑니다.
>
> 수학이 감각이 되는 순간을 직접 느껴보세요.

## 분석

### 구조 (3단 + 행동 유도)
1. **훅 — 시간 절대값**: "40년 동안 단 한 번도" (기간 × 부정형으로 스케일 강조)
2. **팩트 설명**: 일반 모서리의 문제 → 슈퍼엘립스 공식 → "왠지 예뻐 보인다"의 정체 규명
3. **작품 기능 설명**: 손가락 → 격자 → 곡률 변화 → 복원 (인터랙션 흐름 문장화)
4. **행동 유도**: "수학이 감각이 되는 순간을 직접 느껴보세요"

### 화법
- **"단 한 번도", "바로 이것입니다"** — 단호한 수식어로 주장 무게 실음.
- 문제 제기 → 원인 설명 → 해결책 명시 순서로 **교육적 리듬**.
- 수식(`|x|ⁿ + |y|ⁿ = rⁿ`)을 그대로 본문에 삽입 — 팩트 신뢰 + 고급 인상.
- 마지막 한 줄은 **무형 가치 제안**("수학 → 감각") 공식화.

### 재사용 패턴
- **훅 = "X는 Y 동안 단 한 번도 Z하지 않았다"**
- **"느낌의 정체 중 하나가 바로 이것입니다"**  — 독자가 막연히 느끼던 것을 명명
- **마무리: "X가 Y가 되는 순간을 직접 느껴보세요"**
