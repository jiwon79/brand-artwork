# Afterbody

첨부 영상 속 작은 TFT 작품을 웹용 인터랙티브 아트워크로 재구현한다.

## 시각 구성

- 검은 화면 위에 인체 형상 여섯 개가 오른쪽으로 겹쳐진다.
- 오른쪽 잔상일수록 크기가 작고 조밀하다.
- 빨강, 초록, 파랑 채널은 서로 조금씩 어긋나며, 겹치는 곳은 흰색으로 밝아진다.
- 기본 인체는 점이 아니라 둥근 연속 스트로크로 이루어진 `Lines` 모드다.
- 사용자가 제공한 여섯 SVG를 왼쪽부터 순서대로 사용해, 성긴 연속선에서 조밀한 실루엣으로 밀도를 높인다.
- 마지막 SVG의 상체는 촘촘한 선과 RGB 가산 합성이 겹쳐 면처럼 보이며, 하체는 촘촘한 개별 선을 유지한다.
- 같은 마스크를 조밀하게 샘플링한 `Solid` 모드를 함께 제공한다.
- 미세한 화면 모아레나 카메라 압축 노이즈는 재현 대상에서 제외하고, 고해상도 캔버스의 작은 글로우와 스캔라인으로 TFT 질감만 유지한다.

## 입력과 상태

1. `idle`: 인체 잔상이 작은 파동을 유지한다.
2. `Original`은 클릭, 터치, `Space`, `Enter`를 누르면 바로 시작한다. `NameDrop Wave`는 입력을 누르고 있는 동안 `gathering` 상태를 유지하고, 손가락·포인터·키를 떼는 순간 `dissolving`으로 전환한다.
3. `Original`: 붕괴 전선이 왼쪽에서 오른쪽으로 이동하고, 분리된 RGB 입자는 오른쪽으로 확산한다.
4. `NameDrop Wave`: 누르고 있는 동안 실제 SVG 경로에서 떨어져 나온 작은 빛과 짧은 선 꼬리가 입력 좌표로 휘어 들어온다. 인체 선은 형상을 유지한 채 같은 방향으로 조금만 당겨지고 RGB 채널은 접촉점에서 겹치며 밀도가 상승한다. 충분히 모인 뒤에도 입력을 유지하면 중심에서 약한 맥동과 회전을 계속한다. 입력을 떼는 순간 중심에서 시작한 넓고 불규칙한 파동이 바깥으로 진행하면서 경로를 파티클로 해방한다. 별도의 원형 테두리나 얇은 파동선은 그리지 않는다.
5. `blank`: 검은 화면에 머물며 다음 입력으로 다시 재생한다.

키보드 `M`은 두 인체 모드를 전환하고 `R`은 초기 상태로 돌아간다. `G` 또는 `?debug=1`로 lil-gui를 열어 `Interaction`의 `Original / NameDrop Wave`, 잔상 수, RGB 간격, 붕괴 속도, 모이는 시간, 밀도 상승 시간, 선 당김, 파동 속도와 화면 질감을 조절한다.

## 기본 타이밍

- 입력 후 유지: 약 `0.72초`
- 왼쪽 → 오른쪽 붕괴: 약 `3.25초`
- 입자 잔류: 최대 약 `3.35초`
- 전체 시퀀스: 약 `7.8초`

`NameDrop Wave`는 입력을 유지한 첫 `0.92초` 동안 접촉점으로 빛과 짧은 선 꼬리를 모으고, 이어지는 `0.52초` 동안 RGB 간격과 중심 반경을 줄여 밀도를 높인다. 그보다 오래 눌러도 해방은 자동 실행되지 않고 최대 밀도의 맥동을 유지한다. 입력을 떼면 중심과의 거리에 따른 `0.36초`의 파동 지연에 최대 `0.24초`의 불규칙한 방출 시차를 섞어 해방한다. 중심의 확산광은 채워진 소프트 그라디언트이고 경로의 소실 전선도 넓게 분산되어, 얇은 rim 없이 에너지가 한 번에 풀리는 인상을 만든다.

`Lines` 모드는 각 SVG의 실제 Bézier 경로를 `Path2D`로 직접 그린다. 붕괴할 때는 같은 경로의 각 `M` 서브패스를 독립적으로 샘플링해, 분리된 팔·몸통·다리 사이가 임의의 직선으로 연결되지 않도록 한다. `NameDrop Wave`는 이 샘플을 모이는 빛, 짧은 선 꼬리와 방사 파티클의 출발점으로 사용하고, 접촉점까지의 방향으로 실제 경로 자체를 약하게 휘게 한다. `Solid` 모드는 기존 사진에서 복원한 마스크를 유지한다. 픽셀 사각형은 시작 장면에서 사용하지 않고 해방 파동이 도달한 경로 구간에서만 생성한다.
