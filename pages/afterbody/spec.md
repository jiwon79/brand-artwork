# Afterbody

첨부 영상 속 작은 TFT 작품을 웹용 인터랙티브 아트워크로 재구현한다.

## 시각 구성

- 검은 화면 위에 인체 형상 여섯 개가 오른쪽으로 겹쳐진다.
- 오른쪽 잔상일수록 크기가 작고 조밀하다.
- 빨강, 초록, 파랑 채널은 서로 조금씩 어긋나며, 겹치는 곳은 흰색으로 밝아진다.
- 기본 인체는 점이 아니라 둥근 연속 스트로크로 이루어진 `Lines` 모드다.
- 사용자가 제공한 여섯 SVG를 왼쪽부터 순서대로 사용해, 성긴 연속선에서 조밀한 실루엣으로 밀도를 높인다.
- 마지막 SVG의 상체는 촘촘한 선과 RGB 가산 합성이 겹쳐 면처럼 보이며, 하체는 촘촘한 개별 선을 유지한다.
- 같은 마스크를 조밀하게 샘플링한 `Solid` 모드를 함께 제공한다.
- 미세한 화면 모아레나 카메라 압축 노이즈는 재현 대상에서 제외하고, 고해상도 캔버스의 작은 글로우와 스캔라인으로 TFT 질감만 유지한다.

## 입력과 상태

1. `idle`: 인체 잔상이 작은 파동을 유지한다.
2. 클릭, 터치, `Space`, `Enter`: lil-gui에서 선택한 인터랙션을 시작한다.
3. `Original`: 붕괴 전선이 왼쪽에서 오른쪽으로 이동하고, 분리된 RGB 입자는 오른쪽으로 확산한다.
4. `Contact Burst`: 입력 좌표에서 RGB 충격점과 원형 파동이 발생한다. 파동이 실제 SVG 경로를 통과한 구간은 밝게 합쳐진 뒤 파티클로 분해되어 접촉점 바깥 방향으로 방사된다.
5. `blank`: 검은 화면에 머물며 다음 입력으로 다시 재생한다.

키보드 `M`은 두 인체 모드를 전환하고 `R`은 초기 상태로 돌아간다. `G` 또는 `?debug=1`로 lil-gui를 열어 `Interaction`의 `Original / Contact Burst`, 잔상 수, RGB 간격, 붕괴 속도, 접촉 파동, 입자 움직임과 화면 질감을 조절한다.

## 기본 타이밍

- 입력 후 유지: 약 `0.72초`
- 왼쪽 → 오른쪽 붕괴: 약 `3.25초`
- 입자 잔류: 최대 약 `3.35초`
- 전체 시퀀스: 약 `7.8초`

`Contact Burst`의 기본 파동 속도는 디자인 좌표 기준 초당 `176`, 파동 폭은 `18`, 방사 힘은 `62`다. 접촉점에서 각 SVG 샘플까지의 거리가 파티클 생성 시점을 결정하므로 같은 화면에서도 터치 위치에 따라 분해 순서가 달라진다.

`Lines` 모드는 각 SVG의 실제 Bézier 경로를 `Path2D`로 직접 그린다. 붕괴할 때는 같은 경로의 각 `M` 서브패스를 독립적으로 샘플링해, 분리된 팔·몸통·다리 사이가 임의의 직선으로 연결되지 않도록 한다. `Contact Burst`도 이 샘플의 화면 좌표와 접촉점 사이 거리·방향을 사용하므로 파동 전선과 파티클 방사가 원본 SVG 형상 위에서 일어난다. `Solid` 모드는 기존 사진에서 복원한 마스크를 유지한다. 픽셀 사각형은 시작 장면에서 사용하지 않고 붕괴가 시작된 경로 구간에서만 생성한다.
