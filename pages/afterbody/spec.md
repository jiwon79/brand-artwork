# Afterbody

첨부 영상 속 작은 TFT 작품을 웹용 인터랙티브 아트워크로 재구현한다.

## 시각 구성

- 검은 화면 위에 인체 형상 여섯 개가 오른쪽으로 겹쳐진다.
- 오른쪽 잔상일수록 크기가 작고 조밀하다.
- 빨강, 초록, 파랑 채널은 서로 조금씩 어긋나며, 겹치는 곳은 흰색으로 밝아진다.
- 기본 인체는 점이 아니라 둥근 연속 스트로크로 이루어진 `Lines` 모드다.
- 사용자가 제공한 여섯 SVG를 왼쪽부터 순서대로 사용해, 성긴 연속선에서 조밀한 실루엣으로 밀도를 높인다.
- 마지막 SVG의 상체는 촘촘한 선과 RGB 가산 합성이 겹쳐 면처럼 보이며, 하체는 촘촘한 개별 선을 유지한다.
- 같은 마스크를 조밀하게 샘플링한 `Solid` 모드를 함께 제공한다.
- 미세한 화면 모아레나 카메라 압축 노이즈는 재현 대상에서 제외하고, 고해상도 캔버스의 작은 글로우와 스캔라인으로 TFT 질감만 유지한다.

## 입력과 상태

1. `idle`: 인체 잔상이 작은 파동을 유지한다.
2. `Original`은 클릭, 터치, `Space`, `Enter`를 누르면 바로 시작한다. `NameDrop Wave`는 입력을 누르고 있는 동안 `gathering` 상태를 유지하고, 손가락·포인터·키를 떼는 순간 `dissolving`으로 전환한다.
3. `Original`: 붕괴 전선이 왼쪽에서 오른쪽으로 이동하고, 분리된 RGB 입자는 오른쪽으로 확산한다.
4. `NameDrop Wave`: 누르고 있는 동안 별도 점이나 꼬리를 생성하지 않고 실제 SVG 경로 자체를 현재 입력 좌표 쪽으로 국소적으로 늘인다. 손가락이나 포인터가 움직일 때마다 접촉 좌표를 갱신해 당겨진 경로가 계속 따라간다. 멀리 있는 구간은 고정되고 가까운 구간일수록 크게 당겨져, 여러 줄을 한 손으로 잡아당기는 장력을 만든다. 빨강·초록·파랑 경로의 간격은 줄이지 않아 크로마틱 효과를 유지한다. 입력을 떼면 터치점에서 별도 파티클을 만들지 않고, 바깥으로 진행하는 파동이 도달한 SVG 경로 구간만 그 자리에서 파티클로 분해한다. 별도의 원형 테두리나 얇은 파동선도 그리지 않는다.
5. `NameDrop Wave`의 입자가 모두 날아간 뒤에는 자동으로 `idle`의 원래 인체 형상으로 복귀한다. `Original`만 `blank`에 머물며 다음 입력을 기다린다.

키보드 `M`은 두 인체 모드를 전환하고 `R`은 초기 상태로 돌아간다. `G` 또는 `?debug=1`로 lil-gui를 열어 `Interaction`의 `Original / NameDrop Wave`, 잔상 수, RGB 간격, 붕괴 속도, 모이는 시간, 장력 상승 시간, 선 당김, 해방 속도와 화면 질감을 조절한다.

## 기본 타이밍

- 입력 후 유지: 약 `0.72초`
- 왼쪽 → 오른쪽 붕괴: 약 `3.25초`
- 입자 잔류: 최대 약 `3.35초`
- 전체 시퀀스: 약 `7.8초`

`NameDrop Wave`는 입력을 유지한 첫 `0.92초` 동안 SVG 경로를 접촉점 쪽으로 당기고, 이어지는 `0.52초` 동안 장력을 높인다. RGB 경로 간격은 전 구간에서 그대로 유지한다. 그보다 오래 눌러도 해방은 자동 실행되지 않고 최대 장력에서 미세하게 맥동하며 움직이는 접촉점을 추적한다. 입력을 떼면 중심과의 거리에 따른 `0.36초`의 파동 지연에 최대 `0.24초`의 불규칙한 방출 시차를 섞어 해방한다. 해방 후 파티클의 이동과 감쇠는 기본 시간축의 `1.5배` 속도로 재생한다. 중심의 확산광은 채워진 소프트 그라디언트이고 경로의 소실 전선도 넓게 분산되어, 얇은 rim 없이 에너지가 한 번에 풀리는 인상을 만든다. 파티클 수명이 끝나면 즉시 초기 SVG 렌더링으로 복귀한다.

`Lines` 모드는 각 SVG의 실제 Bézier 경로를 `Path2D`로 직접 그린다. 붕괴할 때는 같은 경로의 각 `M` 서브패스를 독립적으로 샘플링해, 분리된 팔·몸통·다리 사이가 임의의 직선으로 연결되지 않도록 한다. `NameDrop Wave`는 이 샘플을 연속선으로 다시 연결한 상태에서 접촉점과의 거리에 따라 경로를 탄성 변형하고, 손을 뗀 뒤에는 파동이 도달한 SVG 샘플 자체만 파티클의 출발점으로 사용한다. 터치 중심에서는 독립 파티클을 생성하지 않는다. `Solid` 모드는 기존 사진에서 복원한 마스크를 유지한다. 픽셀 사각형은 시작 장면이나 홀드 단계에서 사용하지 않고 해방 파동이 도달한 경로 구간에서만 생성한다.
