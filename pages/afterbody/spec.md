# Afterbody

첨부 영상 속 작은 TFT 작품을 웹용 인터랙티브 아트워크로 재구현한다.

## 시각 구성

- 검은 화면 위에 인체 형상 여섯 개가 오른쪽으로 겹쳐진다.
- 오른쪽 잔상일수록 크기가 작고 조밀하다.
- 빨강, 초록, 파랑 채널은 서로 조금씩 어긋나며, 겹치는 곳은 흰색으로 밝아진다.
- 기본 인체는 점이 아니라 둥근 연속 스트로크로 이루어진 `Lines` 모드다.
- 사용자가 제공한 여섯 SVG를 왼쪽부터 순서대로 사용해, 성긴 연속선에서 조밀한 실루엣으로 밀도를 높인다.
- 마지막 SVG의 상체는 촘촘한 선과 RGB 가산 합성이 겹쳐 면처럼 보이며, 하체는 촘촘한 개별 선을 유지한다.
- 같은 마스크를 조밀하게 샘플링한 `Solid` 모드를 함께 제공한다.
- 미세한 화면 모아레나 카메라 압축 노이즈는 재현 대상에서 제외하고, 고해상도 캔버스의 작은 글로우와 스캔라인으로 TFT 질감만 유지한다.

## 입력과 상태

1. `idle`: 인체 잔상이 작은 파동을 유지한다.
2. 클릭, 터치, `Space`, `Enter`: lil-gui에서 선택한 인터랙션을 시작한다.
3. `Original`: 붕괴 전선이 왼쪽에서 오른쪽으로 이동하고, 분리된 RGB 입자는 오른쪽으로 확산한다.
4. `Contact Burst`: 실제 SVG 경로에서 떨어져 나온 작은 빛들이 입력 좌표로 모이고, 인체 잔상과 RGB 채널도 같은 지점을 향해 압축된다. 짧은 충전 뒤 경로 전체가 순차적으로 파티클로 분해되어 접촉점 바깥 방향으로 부드럽게 방사된다. 별도의 원형 테두리나 파동선은 그리지 않는다.
5. `blank`: 검은 화면에 머물며 다음 입력으로 다시 재생한다.

키보드 `M`은 두 인체 모드를 전환하고 `R`은 초기 상태로 돌아간다. `G` 또는 `?debug=1`로 lil-gui를 열어 `Interaction`의 `Original / Contact Burst`, 잔상 수, RGB 간격, 붕괴 속도, 모이는 시간과 압축 강도, 입자 움직임과 화면 질감을 조절한다.

## 기본 타이밍

- 입력 후 유지: 약 `0.72초`
- 왼쪽 → 오른쪽 붕괴: 약 `3.25초`
- 입자 잔류: 최대 약 `3.35초`
- 전체 시퀀스: 약 `7.8초`

`Contact Burst`는 기본 `1.05초` 동안 접촉점으로 모인 뒤 최대 `0.18초`의 불규칙한 간격으로 경로 샘플을 방출한다. 방사 힘은 `86`이며 접선 방향의 흔들림은 작게 제한한다. 거리순으로 잘린 원형 전선을 사용하지 않고 샘플마다 섞인 방출 시점을 사용하므로 얇은 rim 없이 한 덩어리가 충전되었다가 퍼지는 인상을 만든다.

- `assets/sori/figure-1.svg` ~ `figure-6.svg`: 사용자가 제공한 여섯 단계의 연속선 인체 원본

`Lines` 모드는 각 SVG의 실제 Bézier 경로를 `Path2D`로 직접 그린다. 붕괴할 때는 같은 경로의 각 `M` 서브패스를 독립적으로 샘플링해, 분리된 팔·몸통·다리 사이가 임의의 직선으로 연결되지 않도록 한다. `Contact Burst`는 이 샘플을 모이는 빛과 방사 파티클의 출발점으로 사용하고, 접촉점까지의 방향으로 경로 자체를 잠시 압축한다. `Solid` 모드는 기존 사진에서 복원한 마스크를 유지한다. 픽셀 사각형은 시작 장면에서 사용하지 않고 붕괴가 시작된 경로 구간에서만 생성한다.
