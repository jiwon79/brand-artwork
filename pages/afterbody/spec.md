# Afterbody

첨부 영상 속 작은 TFT 작품을 웹용 인터랙티브 아트워크로 재구현한다.

## 시각 구성

- 검은 화면 위에 인체 형상 여섯 개가 오른쪽으로 겹쳐진다.
- 오른쪽 잔상일수록 크기가 작고 조밀하다.
- 빨강, 초록, 파랑 채널은 서로 조금씩 어긋나며, 겹치는 곳은 흰색으로 밝아진다.
- 기본 인체는 점이 아니라 둥근 연속 스트로크로 이루어진 `Lines` 모드다.
- 왼쪽 인물은 성긴 단일선이고, 오른쪽으로 갈수록 선의 진행 방향에 수직인 평행선을 추가해 밀도가 높아진다.
- 마지막 인물의 상체는 평행선과 RGB 가산 합성이 겹쳐 면처럼 보이며, 하체는 촘촘한 개별 선을 유지한다.
- 같은 마스크를 조밀하게 샘플링한 `Solid` 모드를 함께 제공한다.
- 미세한 화면 모아레나 카메라 압축 노이즈는 재현 대상에서 제외하고, 고해상도 캔버스의 작은 글로우와 스캔라인으로 TFT 질감만 유지한다.

## 입력과 상태

1. `idle`: 인체 잔상이 작은 파동을 유지한다.
2. 클릭, 터치, `Space`, `Enter`: 붕괴를 시작한다.
3. `dissolving`: 오른쪽에서 왼쪽으로 붕괴 전선이 이동한다.
4. 분리된 RGB 입자는 오른쪽으로 이동하고 위아래로 확산하며 사라진다.
5. `blank`: 검은 화면에 머물며 다음 입력으로 다시 재생한다.

키보드 `M`은 두 인체 모드를 전환하고 `R`은 초기 상태로 돌아간다. `G` 또는 `?debug=1`로 lil-gui를 열어 잔상 수, RGB 간격, 붕괴 속도, 입자 움직임과 화면 질감을 조절한다.

## 기본 타이밍

- 입력 후 유지: 약 `0.72초`
- 오른쪽 → 왼쪽 붕괴: 약 `3.25초`
- 입자 잔류: 최대 약 `3.35초`
- 전체 시퀀스: 약 `7.8초`

## 소스

- `assets/reference.mp4`: 사용자가 제공한 기준 영상
- `assets/reference-display.png`: 디스플레이 구도 비교용 프레임
- `assets/figure-source.png`: 첫 번째 인체 형상에서 추출한 마스크 원본
- `assets/figure-source-start.png`: 사용자가 지정한 시작 사진의 맨 왼쪽 인물을 잘라낸 선형 기준 소스

`Lines` 모드는 `figure-source-start.png`의 중심선을 가늘게 만든 뒤 끊긴 구간을 방향 연속성에 따라 연결하고, 한 번만 곡선화한다. 각 잔상은 같은 경로를 사용하지만 별도의 스케일과 평행선 간격을 갖는다. `Solid` 모드는 같은 사진에서 복원한 마스크를 사용하므로 모드가 바뀌어도 포즈와 외곽 관계가 유지된다. 픽셀 사각형은 시작 장면에서 사용하지 않고 붕괴가 시작된 경로 구간에서만 생성한다.
